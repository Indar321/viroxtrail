# VIROX Advanced Multi-page Storefront
Open `index.html` in a browser, or use VS Code Live Server. All navigation links open dedicated pages.
Pages include home, shop, product detail, collections, cart, checkout preview, wishlist, search, account, order tracking, size guide, about, contact, FAQs, shipping, returns, refund, privacy, terms (six sections), and cookies.
Deploy to Vercel: upload this folder's contents to GitHub, import the repo into Vercel, choose Framework Preset `Other`, leave Build Command blank, set Output Directory to `.` and deploy.
IMPORTANT: This is a front-end demo. Cart/wishlist use localStorage. Checkout is simulated and does not create real orders or charge payments. Cashfree needs a secure backend; never put secret keys in browser JS. Customer accounts, admin, inventory, order tracking, shipping APIs and email are not connected. Review policies, size chart, product images, prices, support contacts and shipping claims before publishing.

Inspired by the supplied streetwear reference: rotating announcement strip (auto-rotates every 3.8 seconds with previous/next arrows), animated VIROX marquee ticker, oversized cinematic hero wordmark, four image-led category tiles, fresh-drop editorial panel, benefits strip and five-column featured product row. All pages share the rotating announcement and marquee.
